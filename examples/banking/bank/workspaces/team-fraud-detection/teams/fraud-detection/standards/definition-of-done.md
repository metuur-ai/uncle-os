## Team Definition of Done
- Implementation complete, tests pass, peer review done.
- `@spec` markers cover every mandatory clause the change touches.
- Representation of Reality docs updated (the done-gate checks this).
- If the legacy-engine exception was touched, its compensating controls re-verified.
